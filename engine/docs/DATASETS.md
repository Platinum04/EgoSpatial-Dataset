## V4 specification (from `v4/metadata.json`)
- **Splits:** train 4,000, validation 800, test 800. Seed 42. Representation `standard_json`, two objects per scene, object vocabulary of 12.
- **Tasks:** `egocentric` and `object_to_object`. Each task has 5 question variants and 16 heading × direction transformations.
- **Balance:** tasks and transformations are balanced (test has 25 per task × transformation).
- **Hygiene:** deduplicated, with cross-split leakage prevention.
- **Situation format:** `{"agent":{"heading":"<cardinal>"},"objects":[{"id":"<name>","world_direction":"<cardinal>"}, …]}`.
- **Answers:** `front`, `behind`, `left`, `right`, balanced 200 each in validation and test.

## Task semantics (verified in 08E: deterministic solver is 100% on validation and test)
- **egocentric:** the answer is the rotation from the agent heading to the object's world direction. 0° is front, +90° right, 180° behind, 270° left.
- **object_to_object:** the answer is the rotation from the **reference object's direction** to the target's direction. The reference direction acts as "forward", and the agent heading is not used. This differs from the 08B-3 metric relation, which uses the displacement between objects seen in the agent frame.

## Evaluation-only sets created in this phase
These were not used for training.
- **08E paraphrase stress:** 200 test scenes with 3 unseen phrasings per task (seed 7). Stored in `08E/08e_records.json`.
- **11 fresh phrasings:** 240 test scenes with 3 egocentric and 4 object-to-object templates (seed 2027). Stored in `11_evaluation/11_parser_eval.json`.
- **Cross-platform conformance vectors:** 500 random metric scenes and 100 adapter cases. Generated by `tools/make_vectors.py`.

## Limitations
The data cover four cardinal directions only, two objects per scene, and a closed 12-object vocabulary. There is no perception noise or occlusion, and none of it is real sensor data.
